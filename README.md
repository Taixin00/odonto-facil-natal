# Clínica Odonto Fácil Natal

Site institucional responsivo para a Clínica Odonto Fácil Natal.

## Publicação pelo GitHub Pages

1. No repositório, acesse **Settings → Pages**.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch **main** e a pasta **/(root)**.
4. Clique em **Save**. O GitHub publicará o arquivo `index.html`.

## Personalização antes de divulgar

- Substitua as imagens ilustrativas por fotos autorizadas da clínica.
- Adicione depoimentos reais somente com autorização dos pacientes.
- Confira telefone, endereço e horário de atendimento.
- Se desejar, configure um domínio próprio em Settings → Pages.

## Tecnologias

HTML semântico, CSS responsivo e JavaScript puro. Não exige instalação de dependências nem etapa de build.
